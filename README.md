# 鱼头壁纸 · Yutou Wallpaper

> **TrollStore 专用 · TrollStore Only**

## 中文介绍

鱼头壁纸是一款面向 TrollStore 用户的 iPhone 壁纸选择与设置工具。

> **重要说明：**直接设置系统壁纸需要普通签名应用无法获得的系统级权限，因此本软件必须通过 **TrollStore** 安装。使用普通签名、常规侧载或其他不具备相应权限的安装方式时，软件无法直接设置锁屏或主屏幕壁纸。

**真机测试环境：iOS 15.6。** 其他系统版本尚未进行完整验证。

应用可以随机获取多张高清壁纸，以双列布局完整展示图片，并显示每张图片的原始像素尺寸。它能够识别当前设备型号并给出推荐的壁纸尺寸，方便选择更适合屏幕比例的图片。

你可以分别选择锁屏壁纸和主屏幕壁纸，也可以只设置其中一项。候选壁纸会从多个不同专题中均衡随机抽取，并限制并发请求数量，在随机性、加载速度和稳定性之间取得平衡。

### 主要功能

- 随机获取 2～20 张高清壁纸
- 通过 TrollStore 获得直接设置系统壁纸所需权限
- 双列自适应预览，完整显示图片
- 显示图片原始像素尺寸
- 识别设备型号并推荐适合的图像尺寸
- 分别选择锁屏壁纸与主屏幕壁纸
- 支持只设置锁屏或只设置主屏幕
- 支持刷新并重新随机获取候选壁纸
- 针对 iOS 15.6 真机环境测试与优化

## English Introduction

Yutou Wallpaper is an iPhone wallpaper picker and setter designed for TrollStore users.

> **Important:** Directly changing the system wallpaper requires system-level privileges that are unavailable to normally signed apps. This app must therefore be installed through **TrollStore**. When installed with standard signing, regular sideloading, or another method without the required privileges, it cannot directly set the Lock Screen or Home Screen wallpaper.

**Tested on a physical device running iOS 15.6.** Other system versions have not been fully verified.

The app can randomly load multiple high-resolution wallpapers, display each image in a complete two-column preview, and show its original pixel dimensions. It also identifies the current device model and recommends a suitable wallpaper size for the screen.

You can select separate wallpapers for the Lock Screen and Home Screen, or update only one of them. Wallpaper candidates are sampled evenly from multiple collections with controlled request concurrency, providing a balance of variety, loading speed, and stability.

### Main Features

- Randomly load 2–20 high-resolution wallpapers
- Use TrollStore privileges to set the system wallpaper directly
- Adaptive two-column previews that show the complete image
- Display the original pixel dimensions of each wallpaper
- Identify the device model and recommend a suitable image size
- Select separate Lock Screen and Home Screen wallpapers
- Update only the Lock Screen or only the Home Screen
- Refresh and generate a new set of wallpaper candidates
- Tested and optimized on an iOS 15.6 device
